# GitHub認定試験ガイド

## 共通情報

| 項目 | 内容 |
|---|---|
| 試験時間 | 100分 |
| 問題数の目安 | GH-900 約45〜50問 / GH-300 約65問（非公開・受験者の報告による） |
| 出題形式 | 選択式（単一選択・「2つ選べ」などの複数選択）。GH-300はシナリオ問題もあり |
| 合格点 | 700 / 1000 |
| 言語 | 日本語あり |
| 前提条件 | なし |
| 受験料 | 国別価格（米国 $99）。予約時に表示 |
| 再受験 | 不合格後24時間以降 |
| おすすめ順 | GH-900 → GH-300 |

## 受験ステップ

1. Microsoft Learn のプロフィール作成（個人のMicrosoftアカウント推奨）
2. 試験ページから Pearson VUE で予約（オンライン監督 or テストセンター）
3. Microsoft Learn のラーニングパス＋公式学習ガイドで学習。本番の画面操作は [試験サンドボックス](https://aka.ms/examdemo) で事前に体験できる
4. 受験 → 結果は即時、合格でデジタルバッジ発行

---

## GH-900：GitHub Foundations（初級）

GitとGitHubの基礎。開発者以外も対象。2026年1月に出題範囲が大きく改訂。

| 出題分野 | 比重 |
|---|---|
| GitとGitHubの基本 | 25–30% |
| リポジトリの操作 | 10–15% |
| コラボレーション（Issue / PR / レビュー） | 10–15% |
| モダンな開発手法（Actions / Codespaces / InnerSource） | 10–15% |
| プロジェクト管理（GitHub Projects） | 5–10% |
| プライバシー・セキュリティ・管理 | 10–15% |
| GitHubコミュニティ（OSS / ライセンス） | 5–10% |

**学べること：** Gitの仕組みとGitHubでのチーム開発の流れ全体。
**有効期限：** 基礎レベルのため更新不要。

---

## GH-300：GitHub Copilot（中級）

Copilotを正しく安全に使いこなす力。最新範囲は2026年8月7日から適用。

| 出題分野 | 比重 |
|---|---|
| 責任あるAIの使い方 | 15–20% |
| Copilotの機能（IDE / Chat / CLI / Agent Mode / MCP / Spaces） | 25–30% |
| データの流れとアーキテクチャ | 10–15% |
| プロンプトエンジニアリング | 10–15% |
| 開発生産性の向上（生成 / リファクタ / テスト） | 10–15% |
| プライバシー・コンテンツ除外・安全対策 | 10–15% |

**学べること：** Copilotの機能、内部の仕組み、企業導入時の設定とリスク管理。
**有効期限：** 毎年更新（Microsoft Learn上の無料オンライン評価）。
